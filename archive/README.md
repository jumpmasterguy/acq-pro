# Archive

Old files kept for history. Nothing in the app, the build or the GitHub Actions uses them. Moved here on 28 Sep 2026 to clean up the top of the repo.

| Folder | What's in it |
|---|---|
| `one-off-scripts/` | Scripts that ran once: inserting and restructuring lessons, building the template packs (PM Essentials, Proposal Toolkit, CPARS Playbook), stamping the blog byline, checking career-path legs. The `new_*.ts` files are the lesson text those insert scripts pasted into `client/src/lib/curriculum.ts`. |
| `pack-previews/` | Page-by-page PNG previews of template packs 1 to 3 (early versions). |
| `old-patches/` | Patch files left by earlier Claude sessions. Their changes have since landed on `main` or been replaced by later work. Reference only. |

These scripts were written for the file layout of the day they ran. Read one before running it again.
