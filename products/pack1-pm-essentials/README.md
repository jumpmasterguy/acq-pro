# Pack 1 — PM Essentials Templates

Brand: Acqlerate — Defense Acquisitions Academy
Colors: Teal #01696F, Navy #0D1B2A, White/Light Gray backgrounds

## Files

### 1. rfp-compliance-matrix.xlsx
- **Sheet 1 "Compliance Matrix"**: 20 pre-populated DoD RFP requirements (Section L) with columns: Req #, Section L Reference, Requirement Summary, Volume, Page/Section, Response Status (dropdown), Compliance Note, Owner, Due Date
- **Sheet 2 "Instructions"**: How-to guide with column definitions and compliance tips
- Features: Conditional formatting (green/yellow/red), COUNTIF summary dashboard, data validation dropdowns, Excel Table formatting, frozen headers

### 2. risk-register.xlsx
- **Sheet 1 "Risk Register"**: 15 pre-populated defense program risks with Risk Score (formula: P×I), Risk Level (formula: HIGH/MED/LOW), color-scaled heat map
- **Sheet 2 "Risk Matrix Chart"**: 5×5 probability/impact matrix with color-coded risk zones
- Features: COUNTIF summary dashboard by level/category/status, data validation, conditional formatting

### 3. igce-calculator.xlsx
- **Sheet 1 "Labor Estimate"**: 10 LCATs with fully loaded cost formulas (Direct Labor + Fringe + Overhead + G&A)
- **Sheet 2 "ODC & Travel"**: Materials, Equipment, Travel, Subcontracts with 3-year totals
- **Sheet 3 "IGCE Summary"**: Cross-sheet rollup of Labor + ODC with grand totals and IGCE requirements notes
- Features: All costs are live formulas, 3-year breakdown, indirect rate build-up

### 4. stakeholder-raci.xlsx
- **Sheet 1 "RACI Matrix"**: 25 DoD program activities × 10 stakeholder roles with color-coded RACI assignments
- **Sheet 2 "Instructions"**: RACI definitions, stakeholder role descriptions, customization guide
- Features: Color coding (R=teal, A=navy, C=light blue, I=gray), frozen panes, legend

### 5. pm-briefing-deck.pptx
- 12-slide DoD program status review template
- Slides: Cover, Agenda, Executive Summary (traffic lights), Program Status (milestone table), Schedule Status (SPI callout + table), Cost/EVM Status (KPI cards + EVM table), Risk Status, Technical Progress, Contractor Performance (CPARS), Issues & Action Items, Way Forward (30/60/90), Backup/Appendix
- Features: Calibri Bold headings, teal + navy branding, slide numbers, program name/date footer placeholders, realistic DoD PM content examples
